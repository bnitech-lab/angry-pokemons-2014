# Angry Pokemons (2014)

An Android side-scrolling action game written as a university mobile programming project in 2014.

**This is an unofficial student fan game.** It used Pokémon characters that Dawn drew himself. Pokémon and the character names are the property of their owners. This project is not affiliated with, endorsed by, or connected to Nintendo, Game Freak, Creatures or The Pokémon Company.

**All pictures and music have been removed from this copy.** The characters belong to their owners, and the origin of some background and terrain images and of the two music tracks is not known, so none of the art or sound is published here. Only the source code and the text resources remain.

**It will not build as published.** The images and sounds the code loads are missing, and the project depends on the old `appcompat_v7` Eclipse library project, which is not included.

## What the code does

- **Start screen:** a full-screen picture with a "touch the screen" button that opens the main menu.
- **Main menu:** looping background music, a Stage button and an About button.
- **About:** a five-page picture guide with left, right and exit buttons.
- **Stage:** a landscape side-scroller drawn on a `SurfaceView` by a game-loop thread (`StageViewThread`).
  - The background scrolls by itself. Floor blocks are generated ahead of the player with random gaps, and floating platforms appear at random heights.
  - The player can jump and double-jump, and can switch between three characters. Each character fires a different projectile: one moves in a wave and passes through enemies, one bounces off platforms and hits hard once, and one flies straight, can hit several times and pushes enemies back.
  - Four kinds of monsters with their own size, HP, attack and speed come in from the right, more often as time goes on. Touching a monster, or letting one reach the left edge, costs HP and flashes a red warning border. A health item appears from time to time.
  - An on-screen countdown announces the boss. The boss has its own HP bar, gets knocked back when hit hard enough, and hurts the player on contact.
  - Beating the boss opens a black hole on the right, and the player runs off screen into it to finish the stage. Falling into a gap or running out of HP ends the stage.
  - The Back key pauses the game and asks whether to quit.

## Building it today

Eclipse ADT is no longer supported and this has not been tried. A likely route:

1. Create a new Java project in Android Studio with the package name `com.example.mobileproject`.
2. Copy `src/` into `app/src/main/java/`, `res/` into `app/src/main/res/`, and merge the four activities and the storage permission from `AndroidManifest.xml`.
3. Add the AndroidX `appcompat` dependency. `ActionBarActivity` does not exist in AndroidX, so the activities need to extend `androidx.appcompat.app.AppCompatActivity` instead. Raise `minSdkVersion`, since 8 is far below what current libraries support.
4. Supply your own images and sounds under the names the code expects:
   - `res/drawable`: `about0` to `about4`, `background`, `blackholl`, `blockair`, `blockfloor`, `boss1`, `change`, `fireball`, `ggobugi`, `hpitem`, `ic_launcher`, `iceflower`, `jiu`, `lbutton`, `lightning`, `mainbackground`, `monster0` to `monster3`, `pairy`, `pikachu`, `rbutton`, `startbackground`, `title`
   - `res/raw`: `main` (menu music) and `battle` (stage music)

Expect further small fixes after the move.

## What was removed and why

| Removed | Why |
|---|---|
| All 32 images under `res/drawable*` and `ic_launcher-web.png` | Pokémon characters (Dawn's drawings of characters owned by others), title and About screens showing them, and background and terrain images of unknown origin |
| `res/raw/main.mp3`, `res/raw/battle.mp3` | Music of unknown origin |
| `libs/android-support-v4.jar` | Third-party binary from the Android SDK |
| `gen/`, `bin/` | Generated by the build |
| `.classpath`, `.project`, `.settings/` | Eclipse workspace settings |

The Java code and its class, field and resource names are unchanged from 2014. Names such as `Pokemon`, `PokemonSkill` and `pikachu` are left as they were; they are trademarks of their owners and appear only because this was a fan game.
